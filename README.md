Project: Air Quality Analysis

This project cleans air quality data of Indian states using Python and Pandas.
Dataset has 999 rows and 8 columns: Date, City, PM25, PM10, NO2, Temperature_C, Humidity_Percent.

Steps Done:
1. Checked missing values and duplicates
2. Fixed dates and converted columns to numbers
3. Flagged 11 unusual high PM25 values (not deleted)

Files:Air_Quality_1000_Rows.csv(original)
Air_Quality_1000_Rows_Cleaned.csv (cleaned)

Tools: Python, Pandas, Google Colab
